# Introduction
Welcome! This repository contains the code necessary to reproduce the figures of the paper: 

"Demonstrating Single-Photon Counting With Kinetic Inductance Detectors From 4 to 25 um"

This reproduction package has been made by Wilbert Ras-Vinke under an MIT license. For more information see LICENSE
For any questions please contact the author at w.ras@sron.nl

# Structure of the repository
MIR-KIDS/
├── LICENSE
├── README.md
├── requirements.txt
    # list of all dependencies of the respository
├── main.ipynb 
    # Jupyter notebook that contains all the commands and top level variables to reanalyse the data and plot the figures from the paper
├── scripts/  
    # Directory containing the required modules to analyse the raw data
├── figures/
    # Directory containing the figures produces by the scripts
├── analib/  
    # Directory with modules to analyse the multichannel measurement data. These modules are not explicitly used in this repository, but are required for loading the preprocessed measurement data.
